EDUPAGE — установка как приложение
===================================

В папке: index.html (сам дневник), manifest.webmanifest, sw.js (работа без интернета), icons/ (иконки).
Папку нужно выложить в интернет (бесплатно) — тогда дневник можно установить как приложение.

1) ВЫЛОЖИТЬ ПАПКУ
   Любой бесплатный хостинг статических сайтов с https, например Netlify Drop или GitHub Pages.
   Перетащи всю папку (не zip) — получишь адрес вида https://что-то.netlify.app

2) УСТАНОВИТЬ (тот же адрес на всех устройствах)
   • Mac, Chrome:   значок установки справа в адресной строке  →  Установить
   • Mac, Safari:   Файл → Добавить в Dock
   • iPhone/iPad:   Safari → Поделиться → На экран «Домой»
   • Android:       Chrome → меню ⋮ → Установить приложение

3) ДАННЫЕ
   Данные хранятся только на том устройстве, где ты работаешь. Между устройствами переноси так:
   Dashboard → Export Data  →  Import Data на другом устройстве.
   ВАЖНО: на iPhone приложение с экрана «Домой» хранит данные отдельно от Safari —
   нажимай Import Data уже внутри приложения.
   Не нажимай «Очистить данные сайта» в настройках браузера.

4) ОБНОВЛЕНИЕ
   Выложи новые файлы на ТОТ ЖЕ сайт (не создавай новый — у нового сайта будут пустые данные).
   Приложение само подтянет новую версию при следующем открытии с интернетом.
